# The Paperboy Times — client-meeting broadsheet (Jul 22, 2026)

Two-page printed newspaper for the Kyle meeting. Page 1 is the showpiece front page
(reusable with LPs / the Chief-of-Staff hire); page 2 is the honest working roadmap.

**File:** `paperboy-broadsheet.html` — fully self-contained (fonts load from one
Google Fonts link; needs internet the first time it opens so the typefaces load).

## How to print

1. Open `paperboy-broadsheet.html` in **Chrome** (double-click, or drag onto Chrome).
2. Wait a second for the fonts to load, then **⌘P** (Print).
3. Set exactly:
   - **Destination:** your printer (or "Save as PDF" for a proof)
   - **Paper size:** **Letter**
   - **Layout:** **Portrait**
   - **Margins:** **None** (if your printer refuses, **Minimum**)
   - **Scale:** Default / 100%
   - **More settings → Background graphics: ON** ← required, or the cream paper won't print
4. The preview must show **exactly 2 pages**. If it shows 3, margins are not on
   None/Minimum or scale isn't 100%.

Prints beautifully in black-and-white too — the bronze accents fall back to a dark gray.

Best on cream or ivory paper stock if you have it; standard white works fine.
